## 🚀 How to Run the Program

To execute the entire ShinePro Auto Care system, you must run the main application controller, which serves as the landing page and distributes traffic to each member's individual role module.

### 1. Prerequisites & File Organization

* Ensure **Python 3.x** is installed on your local machine.
* All group members' Python files (`main.py`, `facility_assistant.py`, `administrator.py`, etc.) and all flat text files (`bays.txt`, `supplies.txt`, `reports.txt`, `customers.txt`, etc.) **must** be placed together in the exact same root folder directory.

### 2. Opening the Project Directory

* **On Windows:** Open your project folder in File Explorer, click on the address bar at the top, type `cmd`, and press `Enter`. This opens a Command Prompt window pre-targeted to your project files.
* **On macOS / Linux:** Open your terminal and use the change directory command (`cd`) to navigate to your project folder, or right-click the folder and select *New Terminal at Folder*.

### 3. Launching the Application

Run the main controller file by entering the following command into your terminal:

```bash
python main.py

```

*(Note: Depending on your local environment configuration, macOS users may need to explicitly execute `python3 main.py` instead).*
